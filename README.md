# codetrans-backend

This is the codetrans backend, where every processing happen, parsing, translation, merging etc...
Codetrans is a vs Code extension, that basically translates token(comments, variables name and other user defined identifiers). It actually supports english-french version

it is link to the **codetrans** extension on [codetrans](https://github.com/L3m1K0uad10/codetrans)
